# social-anxiety-prediction-analysis
This project conducts a comprehensive exploratory data analysis (EDA) on a dataset related to social anxiety. The analysis involves cleaning missing values, treating outliers, investigating statistical relationships between various lifestyle and physiological factors, and performing feature engineering (like binning and merging rare categories) to prepare the data for machine learning. Key insights include the distribution of anxiety across different demographics, correlations with factors like sleep hours and stress levels, and the creation of a processed dataset ready for model building.
